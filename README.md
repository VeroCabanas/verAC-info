# verAC

## Verificación de archivos de acelerometría Matrix

**Autora:** Verónica Cabanas Sánchez · Universidad Autónoma de Madrid.

Herramienta para Windows que automatiza la lectura, la verificación técnica inicial, la generación de informes y la organización de archivos `.bin` de acelerometría Matrix de muñeca y muslo. Fue desarrollada para el control de calidad de registros de la cohorte IMPaCT.
